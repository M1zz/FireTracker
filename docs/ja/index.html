Toesagak

資産・純資産・FIRE(早期リタイア)目標をひと目で管理するアプリ

はじめに

Toesagak は、持っている資産と負債を登録するだけで総資産と純資産を計算し、 毎月の記録から資産の推移とFIRE(経済的自立)目標の達成率を確認できる 個人向けの資産管理アプリです。データはすべてお使いの端末内にのみ保存され、会員登録も不要です。

主な機能

  • 📊株式・暗号資産・不動産・現金・年金・負債などをカテゴリ別に管理し、銘柄ごとに詳しく記録
  • 📈資産・負債・純資産の月別推移グラフと、前回の記録からの増減
  • 🎯目標支出額と取り崩し率にもとづく FIRE 達成率と、年末時点の予測
  • 📡ティッカーや銘柄コードを入力するだけで、米国株・韓国株・暗号資産・韓国の不動産の相場を自動取得
  • 🖼️証券アプリの保有銘柄スクリーンショットを端末内で読み取り、まとめて追加

よくある質問

資産データはどこに保存されますか?

すべてお使いの端末内(Apple SwiftData)にのみ保存されます。サーバーにアップロードされることはなく、開発者が見ることもできません。

相場が自動で取得されません。

米国株・暗号資産・為替レートはキーなしで利用できます。韓国株と不動産の相場は、設定タブで対応する API キー(韓国投資証券、韓国の公共データポータル)を入力する必要があります。ネットワーク接続と、ティッカー/銘柄コードが正しいかもあわせてご確認ください。

データを削除するには?

アプリを削除すると、端末に保存されたデータもすべて削除されます。

総資産と純資産の違いは何ですか?

アプリでは「総資産」は保有している資産の合計、「純資産」はそこから負債を差し引いた額(総資産 − 負債)です。
