개인정보처리방침

앱: 퇴사각 · 시행일: 2026년 9월 10일

요약: 퇴사각은 회원가입이 없고, 사용자의 재무 데이터를 개발자의 서버로 수집·저장하지 않습니다. 데이터는 사용자의 기기에 저장되며, 사용자가 iCloud 동기화를 켠 경우에만 사용자 본인의 iCloud 계정에도 저장됩니다.

1. 수집·저장하는 정보

사용자가 입력하는 자산·부채·수입·지출·목표 등 모든 재무 데이터는 전적으로 사용자의 기기 내부 (Apple SwiftData)에만 저장됩니다. 개발자를 포함한 제3자는 이 데이터에 접근할 수 없으며, 별도의 계정 생성이나 로그인이 없습니다. 앱은 이름·이메일·전화번호 등 개인 식별정보를 수집하지 않습니다.

iCloud 동기화(선택): 설정에서 iCloud 동기화를 켜면, 같은 재무 데이터가 사용자 본인의 Apple 계정에 속한 iCloud 비공개 데이터베이스에도 저장되어 같은 계정의 다른 기기와 동기화됩니다. 이 데이터베이스는 사용자 본인만 접근할 수 있으며 개발자는 내용을 볼 수 없습니다. 끄면 이후 변경은 기기에만 저장됩니다.

2. 시세 자동 조회 시 외부로 전송되는 정보

‘시세 자동’ 기능을 사용할 때, 사용자가 입력한 조회 식별자(종목코드·티커·코인 심볼·법정동코드)가 현재가를 받아오기 위해 아래 외부 서비스로 전송됩니다.

  • Finnhub — 미국 주식 시세
  • 한국투자증권(KIS) Open API — 국내 주식 시세
  • 업비트(Upbit) — 암호화폐 시세
  • 공공데이터포털(국토교통부) — 부동산 실거래가
  • 환율 제공처 — 통화 환산

이때 전송되는 것은 조회 대상 식별자뿐이며, 보유 수량·평가액·자산 총액 등 개인 재무정보나 신원정보는 전송되지 않습니다. 각 서비스로 전송된 요청의 처리에는 해당 서비스의 개인정보 방침이 적용됩니다.

3. 스크린샷 가져오기

증권사 보유종목 스크린샷으로 자산을 추가하는 기능은 Apple의 온디바이스 Vision으로 기기 내부에서만 이미지를 인식하며, 이미지나 인식 결과를 외부로 전송하거나 저장하지 않습니다.

4. 광고·추적 및 익명 사용 통계

앱은 광고를 넣지 않고, 상용 분석 SDK를 쓰지 않으며, 다른 앱·웹사이트를 넘나드는 사용자 추적(트래킹)을 하지 않습니다. 광고 식별자(IDFA)도 사용하지 않습니다.

다만 앱이 실제로 쓰이는지 파악하기 위해 익명 사용 통계를 개발자의 iCloud(CloudKit) 저장소로 보냅니다. 여기에 포함되는 것은 다음이 전부입니다.

  • 앱 실행 횟수, 설치 후 경과일, 앱 버전, OS 버전, 기기 종류, 언어 설정
  • 기능 사용 여부 — 등록한 자산 개수, 기록 개수, 매매 기록 개수, 시세 자동 사용 여부, 계산 탭에서 사용한 모드 등 개수와 켜짐/꺼짐

금액은 전송되지 않습니다. 자산·부채·수입·지출·순자산 등 사용자가 입력한 숫자와 종목명은 어떤 형태로도 나가지 않습니다. 통계는 이름·이메일·전화번호·기기 식별자 같은 개인 식별정보 없이, 기기·계정과 무관한 무작위 설치 식별자(UUID)로만 묶입니다. 이 식별자는 앱을 지웠다 다시 설치하면 새로 만들어져 이전 기록과 연결되지 않습니다.

5. 피드백 보내기

설정의 ‘피드백 보내기’로 의견을 보내면, 사용자가 적은 내용(의견 유형, 메시지, 첨부한 스크린샷, 회신용으로 남긴 이름·이메일)과 앱 버전·기기 종류·OS 버전·언어 설정이 Apple iCloud(CloudKit) 저장소를 거쳐 개발자에게 전달됩니다. 답변과 앱 개선에만 쓰며, 보내지 않으면 아무것도 전송되지 않습니다. 이름·이메일은 적지 않아도 됩니다.

6. 오류 진단

앱이 비정상 종료되거나 멈추면, iOS가 기기에서 만들어 주는 진단 정보(MetricKit) 중 오류가 난 코드 위치(콜스택), 앱 버전, OS 버전, 기기 종류를 iCloud(CloudKit) 저장소로 보내 오류를 고치는 데 씁니다. 재무 데이터나 개인 식별정보, 설치 식별자는 포함되지 않습니다.

7. 인앱 결제

‘퇴사각 프로’ 구매와 복원은 Apple App Store가 처리합니다. 결제 수단 등 결제 정보는 개발자에게 전달되지 않으며, 앱은 구매 여부(권한)만 기기에서 확인합니다.

8. 앱 잠금(Face ID · Touch ID)

앱 잠금을 켜면 Apple의 생체 인증으로 본인을 확인합니다. 인증은 iOS가 처리하며, 앱은 얼굴·지문 정보에 접근하거나 저장하지 않습니다.

9. 데이터 보관 및 삭제

데이터는 기기에 저장되므로, 앱을 삭제하면 기기의 데이터도 함께 삭제됩니다. 기기에서 iCloud 백업을 사용하는 경우 해당 백업은 Apple의 기기 백업 정책을 따릅니다. iCloud 동기화를 켰던 경우 iCloud에 남은 데이터는 iOS 설정 ▸ Apple 계정 ▸ iCloud ▸ 계정 저장 공간 관리에서 ‘퇴사각’ 데이터를 지워 삭제할 수 있습니다.

10. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
