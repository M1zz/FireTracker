ติดตามสินทรัพย์ ความมั่งคั่งสุทธิ และเป้าหมาย FIRE (เกษียณก่อนกำหนด) ได้ในที่เดียว

เกี่ยวกับแอป

Toesagak เป็นแอปติดตามการเงินส่วนบุคคล เพียงบันทึกสินทรัพย์และหนี้สินที่มี แอปจะคำนวณสินทรัพย์รวมและความมั่งคั่งสุทธิให้ และเมื่อบันทึกทุกเดือน คุณจะเห็นแนวโน้มการเปลี่ยนแปลงและความคืบหน้าสู่เป้าหมาย FIRE (อิสรภาพทางการเงิน) ข้อมูลทั้งหมดเก็บไว้ในอุปกรณ์ของคุณเท่านั้น และไม่ต้องสมัครสมาชิก

ฟีเจอร์หลัก

  • 📊จัดการสินทรัพย์ตามหมวดหมู่ เช่น หุ้น คริปโต อสังหาริมทรัพย์ เงินสด เงินบำนาญ และหนี้สิน พร้อมบันทึกรายละเอียดรายตัว
  • 📈กราฟแนวโน้มรายเดือนของสินทรัพย์ หนี้สิน และความมั่งคั่งสุทธิ พร้อมส่วนต่างจากการบันทึกครั้งก่อน
  • 🎯ความคืบหน้า FIRE ตามค่าใช้จ่ายเป้าหมายและอัตราการถอนเงิน พร้อมคาดการณ์ ณ สิ้นปีนี้
  • 📡ใส่ตัวย่อหรือรหัสหุ้น แล้วดึงราคาหุ้นสหรัฐฯ หุ้นเกาหลี คริปโต และอสังหาริมทรัพย์ในเกาหลีได้อัตโนมัติ
  • 🖼️อ่านภาพหน้าจอรายการหุ้นที่ถือจากแอปโบรกเกอร์ภายในอุปกรณ์ แล้วเพิ่มทั้งหมดได้ในครั้งเดียว

คำถามที่พบบ่อย

ข้อมูลสินทรัพย์ของฉันถูกเก็บไว้ที่ไหน

เก็บไว้ในอุปกรณ์ของคุณเท่านั้น (Apple SwiftData) ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์ และผู้พัฒนาก็มองไม่เห็นข้อมูลนี้

ราคาไม่อัปเดตอัตโนมัติ

หุ้นสหรัฐฯ คริปโต และอัตราแลกเปลี่ยนใช้งานได้โดยไม่ต้องมีคีย์ ส่วนราคาหุ้นเกาหลีและอสังหาริมทรัพย์ต้องใส่ API key ที่เกี่ยวข้อง (Korea Investment & Securities และพอร์ทัลข้อมูลสาธารณะของเกาหลี) ในแท็บการตั้งค่า โปรดตรวจสอบการเชื่อมต่ออินเทอร์เน็ตและความถูกต้องของตัวย่อหรือรหัสหุ้นด้วย

ต้องการลบข้อมูลต้องทำอย่างไร

เมื่อลบแอป ข้อมูลทั้งหมดที่เก็บไว้ในอุปกรณ์จะถูกลบไปด้วย

สินทรัพย์รวมกับความมั่งคั่งสุทธิต่างกันอย่างไร

ในแอป “สินทรัพย์รวม” คือผลรวมของทุกสิ่งที่คุณมี ส่วน “ความมั่งคั่งสุทธิ” คือส่วนที่เหลือหลังหักหนี้สินแล้ว (สินทรัพย์รวม − หนี้สิน)
