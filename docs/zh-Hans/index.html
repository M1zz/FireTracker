Toesagak

资产、净资产、FIRE(提前退休)目标，一目了然

简介

Toesagak 是一款个人财务追踪应用。录入你的资产和负债，即可算出总资产与净资产； 每月记录一次，就能看到资产变化趋势和FIRE(财务自由)目标完成度。 所有数据仅保存在你的设备上，无需注册账号。

主要功能

  • 📊按类别管理股票、加密货币、房产、现金、养老金、负债等资产，并可逐项记录持仓明细
  • 📈资产、负债、净资产的月度趋势图，以及与上次记录相比的变化
  • 🎯根据目标支出和提取率计算 FIRE 完成度，并预测今年年底的情况
  • 📡输入股票代码即可自动获取美股、韩股、加密货币及韩国房产的行情
  • 🖼️在设备上识别券商 App 的持仓截图，一次性批量添加

常见问题

我的资产数据保存在哪里？

全部只保存在你的设备上(Apple SwiftData)。不会上传到服务器，开发者也无法查看。

行情无法自动获取。

美股、加密货币和汇率无需密钥即可使用。韩股和房产行情需要在“设置”标签页中填写对应的 API 密钥(韩国投资证券、韩国公共数据门户)。另外请检查网络连接，并确认股票代码填写正确。

如何删除数据？

删除应用后，设备上保存的所有数据会一并删除。

总资产和净资产有什么区别？

在本应用中，“总资产”是你所拥有资产的总和，“净资产”是总资产减去负债后的金额(总资产 − 负债)。
