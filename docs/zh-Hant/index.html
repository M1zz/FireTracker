Toesagak

資產、淨資產、FIRE(提早退休)目標，一目了然

簡介

Toesagak 是一款個人理財追蹤 App。登錄你的資產與負債，就能算出總資產與淨資產； 每個月記錄一次，即可看到資產變化趨勢與FIRE(財務自由)目標達成率。 所有資料只儲存在你的裝置上，不需要註冊帳號。

主要功能

  • 📊依類別管理股票、加密貨幣、不動產、現金、退休金、負債等資產，並可逐檔記錄持股明細
  • 📈資產、負債、淨資產的每月趨勢圖，以及與上次記錄相比的變化
  • 🎯依目標支出與提領率計算 FIRE 達成率，並預估今年年底的情況
  • 📡輸入股票代號即可自動取得美股、韓股、加密貨幣及韓國不動產的行情
  • 🖼️在裝置上辨識券商 App 的持股截圖，一次全部加入

常見問題

我的資產資料儲存在哪裡？

全部只儲存在你的裝置上(Apple SwiftData)。不會上傳到伺服器，開發者也看不到。

行情無法自動更新。

美股、加密貨幣與匯率不需金鑰即可使用。韓股與不動產行情需要在「設定」分頁輸入對應的 API 金鑰(韓國投資證券、韓國公共資料入口網站)。也請確認網路連線，以及股票代號是否正確。

如何刪除資料？

刪除 App 後，裝置上儲存的所有資料也會一併刪除。

總資產和淨資產有什麼不同？

在 App 中，「總資產」是你所擁有資產的總和，「淨資產」則是總資產扣除負債後的金額(總資產 − 負債)。
